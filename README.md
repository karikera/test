# 숫자 야구 게임

Node.js로 만든 간단한 숫자 야구 게임입니다.

## 실행 방법

1. Node.js를 설치해야 합니다.
2. 터미널에서 다음 명령어를 실행하여 게임을 시작합니다.

```bash
node index.js
```

## 게임 규칙

1. 컴퓨터는 중복되지 않는 3개의 숫자를 생성합니다.
2. 사용자는 3자리 숫자를 입력하여 컴퓨터가 생성한 숫자를 추측합니다.
3. 사용자가 입력한 숫자와 컴퓨터가 생성한 숫자를 비교하여 다음과 같은 결과를 알려줍니다.
   - **스트라이크(Strike):** 숫자와 위치가 모두 일치하는 경우
   - **볼(Ball):** 숫자는 일치하지만 위치가 다른 경우
4. 9번의 기회가 주어지며, 그 안에 3스트라이크를 기록하면 사용자의 승리입니다.
5. 9번의 기회를 모두 사용하면 게임이 종료됩니다.
